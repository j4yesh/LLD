1.Adapter Pattern

q.what is it?
ans: act as bridge between two incompetable interface to work together by converting
    the interface of existing class into client expects

q.what problem does it solves?
ans: it solves the incompatiblility between existing class and client code that wants to 
    use them

q.how does it works?
ans : pass the instance of target object in Adapter object, define the methods
    where are simply calling the couple of methods accordingly

q.real world example?
ans: Payment Gateaways,Legacy logger,Media Player

2.Composite Pattern

q.what is it?
ans : allows to control the complex hierachies , control the set of object in 
         unified way

q.what problem does it solve?
ans: tidious to control the hierachies of object

q.how does it works?
ans: maintain the unified interface for both indivisual objects and groups,where the 
    composite class stores a collection of objects implementing that interface. implement
    the methods that iterate through the children and invoke the relevant operations,
    allowing indivisual objects and group to be controll uniformly

q.real world example
ans : to control the behavior of NPCs in game
