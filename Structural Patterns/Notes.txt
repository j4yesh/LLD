1.Adapter Pattern

q.what is it?
ans: act as bridge between two incompetable interface to work together by converting
    the interface of existing class into client expects

q.what problem does it solves?
ans: it solves the incompatiblility between existing class and client code that wants to 
    use them

q.how does it works?
ans : pass the instance of target object in Adapter object, define the methods
    where are simply calling the couple of methods accordingly

q.real world example?
ans: Payment Gateaways,Legacy logger,Media Player

2.Composite Pattern

q.what is it?
ans : allows to control the complex hierachies , control the set of object in 
         unified way

q.what problem does it solve?
ans: tidious to control the hierachies of object

q.how does it works?
ans: maintain the unified interface for both indivisual objects and groups,where the 
    composite class stores a collection of objects implementing that interface. implement
    the methods that iterate through the children and invoke the relevant operations,
    allowing indivisual objects and group to be controll uniformly

q.real world example
ans : to control the behavior of NPCs in game

3.Facade Pattern

q.what is it?
ans : gives single point of access for the subsystem

q.what problem does it solve?
ans : want to manage the multiple things from single point,hide complexity
    and provide clean and simplified interface

q.how does it works?
ans : create the facade class which will hold the instance of 
        sysystem object and use them accordingly

q.real world example?
ans : Media player, Game Environment Manager


4.Decorator Pattern

q.what is it?
ans : allows to control the functionality of objects dynamically

q.what problem does it solve?
ans : how to add new functionality to object without altering their code 

q.how does it works?
ans : define common interface for base class,using Decorators to wrap objects,
    adding new behavior while preserving original object interface

q.real world example?
ans : alter the behavior of NPCs in a game,Coffee ordering,Java I/O BufferInputStream

Note: Decorator make it easy to add the functionality dynamically, but removing 
    specific decorator from an already wrapped object is directly supported by Pattern
    to solve it 1.rebuild decorator chain
                2.use removable ability another class which will add/remove ability
